核心流程

从意图到执行的五个阶段

01
意图解析 LLM
从自然语言中提取结构化约束：场景（家庭/朋友）、人数、时长、距离限制、饮食偏好、特殊需求（带娃/减肥/预算）。 输出标准化的 Intent JSON。
02
信息收集 Tool Calls
LLM 作为大脑，按需调用 Tool 收集信息：搜索周边 POI、查找匹配餐厅、查询实时排队情况、检查活动日历。 采用 ReAct 模式——思考→行动→观察，循环直到信息充分。
03
方案编排 LLM
将收集到的 POI、餐厅、活动按时间线串联。考虑地理位置就近原则、人群体力（5岁孩子）、用餐时间窗口、 排队等待时间等约束，生成最优时间线。
04
用户确认 交互
输出人可读的方案摘要，支持用户提出修改意见："换一家餐厅"、"加一个咖啡馆"、"孩子4点要午睡"。 多轮对话迭代直到用户满意。
05
一键执行 Tool Calls
用户确认后，批量调用执行类 Tool：购买门票、餐厅排号/预订、下单配送（蛋糕/鲜花）。 返回所有订单状态，生成最终可执行方案。
工具设计

9 个核心 Tool

分为查询类和执行类，覆盖 POI、餐厅、票务、配送四大场景。

search_poi()
category, location, distance_limit → POI列表
get_poi_detail()
poi_id → 评分、营业时间、适合人群
search_restaurant()
tags, location, party_size → 餐厅列表
check_waitlist()
restaurant_id → 当前排队人数、预计等待
reserve_table()
restaurant_id, time, party_size → 预订结果
buy_ticket()
venue_id, quantity → 订单号、二维码
check_event()
location, date → 活动列表（展览/市集/演出）
order_delivery()
item, address, time → 配送单号、预计送达
search_coupon()
scope_type, scope_id → 团购/满减/折扣券列表
